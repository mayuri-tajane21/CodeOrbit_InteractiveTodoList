# Personal Portfolio Website

# About the Project
This is a responsive personal portfolio website developed as part of the CodeOrbit Tech Frontend Development Internship. It showcases my introduction, technical skills, projects, and contact information.

# Features
- About Me section
- Skills section
- Projects section
- Contact section
- Responsive layout for mobile and desktop screens
- Simple and consistent design

# Technologies Used
- HTML5
- CSS3
- JavaScript

# Project Structure

CodeOrbit_PersonalPortfolio/
├── index.html
├── style.css
├── script.js
└── README.md

# How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your web browser.

# Purpose
The purpose of this project is to practice HTML, CSS, and JavaScript and build a personal website to showcase my skills and projects.
