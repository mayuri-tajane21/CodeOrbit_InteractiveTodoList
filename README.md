# Interactive To-Do List App

# About the Project
This project is an interactive To-Do List application developed as part of the CodeOrbit Tech Frontend Development Internship. It helps users manage their daily tasks through a simple and user-friendly interface.

# Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Update the task list dynamically using JavaScript
- Save tasks in browser localStorage
- Retain saved tasks after refreshing the page
- Simple and responsive user interface

# Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

# Project Structure

CodeOrbit_ToDoList/
├── index.html
├── style.css
├── script.js
└── README.md


# How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your web browser.
4. Add tasks and test the available features.

# Purpose
The purpose of this project is to practice JavaScript DOM manipulation, event handling, and localStorage while building an interactive task management application.
